# Samsung Health Dashboard

A Python tool that turns a raw Samsung Health data export into a clean, interactive HTML dashboard covering steps, sleep, heart rate, exercise, nutrition, and weight.

**[View the live demo](https://YOUR-USERNAME.github.io/samsung-health-dashboard/samsung_health_dashboard.html)** (built from generated sample data, not real health data)

![Dashboard preview](screenshots/dashboard.png)

## What it does

- Finds the right files automatically in a Samsung Health export, even inside nested folders
- Cleans and reshapes six different data sources into daily and weekly metrics
- Builds interactive Plotly charts with 7-day rolling averages, goal lines, and zoom controls (1M / 3M / 6M / 1Y / All)
- Shows summary cards: average steps, sleep, resting heart rate, active minutes, calories, and weight change
- Outputs a single self-contained HTML file that opens in any browser, with no server needed

## Working with messy real-world data

Samsung Health exports are not analysis-ready, and most of the work in this project is data cleaning:

- **Metadata row:** every CSV starts with a metadata line before the real header, which has to be skipped.
- **Misaligned columns:** data rows contain one more field than the header. After parsing, values land one column off from their labels (for example, the step count sits under `source_type`), so each loader maps the columns where the values actually land rather than trusting the headers.
- **Inconsistent formats:** dates appear as formatted strings in some files and Unix millisecond timestamps in others; durations come in milliseconds or seconds; distances in meters or kilometers. The loaders detect and normalize these.
- **Duplicate records:** step data can contain several rows per day from different sources, so the loader keeps the primary source and takes the daily maximum to avoid double counting.
- **Sleep that crosses midnight:** each sleep is credited to the day you wake up, so a night that starts after midnight isn't merged with the previous night.
- **Outliers:** heart rate readings outside 30–220 bpm and sleep sessions under 30 minutes or over 16 hours are filtered out.

## Tech stack

Python, pandas, Plotly, HTML/CSS

## Run it yourself

Install the requirements:

```
pip install pandas plotly numpy
```

**With sample data** (no Samsung account needed):

```
python generate_sample_data.py
python samsung_health_dashboard.py
```

Then open `samsung_health_dashboard.html` in a browser.

**With your own data:** in the Samsung Health app, go to Settings → Download personal data, copy the export to your computer, and run:

```
python samsung_health_dashboard.py --data-dir "path/to/your/export"
```

### Options

| Option | What it does |
|---|---|
| `--data-dir` | Folder containing the Samsung Health export (default: `sample_data`) |
| `--output` | Where to save the dashboard (default: `samsung_health_dashboard.html`) |
| `--days` | Only include the last N days |
| `--diagnose` | Print column names and sample values, useful when a new export format doesn't parse |

## Project structure

```
├── samsung_health_dashboard.py   # loads, cleans, and charts the data
├── generate_sample_data.py       # creates realistic fake exports in Samsung's format
├── sample_data/                  # generated sample CSVs
├── samsung_health_dashboard.html # dashboard built from the sample data
└── screenshots/
```

## Privacy

No real health data is included in this repository. The demo and the sample CSVs are generated by `generate_sample_data.py`, which mimics Samsung's file layout with realistic but fake values (fixed random seed, so the output is reproducible).
